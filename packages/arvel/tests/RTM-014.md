### Spec drift caught and corrected

- **Test path**: PRD-014 § 2 originally said `tests/integration/test_pusherjs_wire_contract.py`. Implementation lives at `packages/arvel/tests/integration/test_pusherjs_wire_contract.py` (matches existing project convention; new top-level `tests/` directory would have needed pytest testpath additions and would have been the only top-level `tests/` in the workspace). PRD updated at Stage 4 with the corrected path.
- **Typer command names**: original `@app.command()` without explicit names caused `app.registered_commands[*].name == None`. Fixed in 14-S1 by passing explicit `name=` to all three commands.
- **pusher-js ESM shape**: 14-S2 first draft used `import Pusher from 'pusher-js'`; pusher-js@8.5.0 actually exports `{ Pusher }` (CommonJS interop), so `import { Pusher } from 'pusher-js'` is the correct form. Fixed in 14-S2.
- **Memory benchmark semantics**: 14-S3 first draft measured absolute `ru_maxrss` and FAILed (82 MiB vs 64 MiB target) because it included the Python runtime + arvel imports + pytest harness in the measurement. NFR-013-003 specifies the *incremental* cost of the broadcasting subsystem; refactored to sample before/after deltas, PASSes trivially. Documented in the bench module's docstring and in ADR-061.

No other spec drift. PRD-014 is conformant.
