### FR-023-003 — Migration table generators

Superseded. The old per-table generators (`make:cache-table`, `make:queue-table`,
`make:session-table`, `make:queue-failed-table`, `make:notifications-table`)
were replaced by `arvel vendor:publish` (see `test_vendor_publish.py`). Each
feature provider registers its canonical migration stub via
`self.publishes(...)` in `boot()`; consumers stamp them into
`database/migrations/` with `--tag=arvel-<feature>`.

## Red-state verification

At Stage 3a exit, running pytest against the new test files MUST yield import errors (modules not yet present) for every test. No test may accidentally pass.

```bash
# Expected: collection error / import failure on every new test file
cd packages/arvel && uv run pytest tests/console/test_migrate_reset_family.py \
  tests/console/test_make_commands_023.py \
  tests/console/test_maintenance_mode.py \
  tests/console/test_queue_ops_023.py \
  tests/console/test_introspection.py \
  tests/console/test_aliases_023.py --collect-only 2>&1 | head -40
```
