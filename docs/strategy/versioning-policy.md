# Versioning Policy

Arvel follows [Semantic Versioning 2.0.0](https://semver.org/) (`MAJOR.MINOR.PATCH`).

## Version Components

### MAJOR

Increment when making incompatible public API changes — removing or renaming exported
symbols, changing method signatures in a breaking way, or altering documented runtime
behaviour that existing callers depend on.

A MAJOR bump signals that consumers must update their code before upgrading.

### MINOR

Increment when adding functionality in a backward-compatible manner — new classes,
new optional parameters, new CLI commands, or new configuration keys that existing
apps can safely ignore.

A MINOR bump is safe to adopt without code changes.

### PATCH

Increment for backward-compatible bug fixes — correcting incorrect behaviour without
changing the public contract, updating documentation, or fixing internal implementation
details that don't affect the observable API.

## Pre-release Labels

- `alpha` — unstable API, may change without notice (`1.0.0-alpha.1`)
- `beta` — feature-complete, breaking changes unlikely (`1.0.0-beta.1`)
- `rc` — release candidate, no planned changes (`1.0.0-rc.1`)

## Deprecation Policy

A symbol or behaviour is deprecated before removal:

1. Mark it deprecated in the current MINOR release (doc comment + runtime warning).
2. Keep it functional for at least one full MINOR cycle.
3. Remove it in the next MAJOR release.

Deprecation notices include the version in which the symbol will be removed and a
migration path to the replacement.

Deprecation does **not** apply to symbols marked `_private` (single leading underscore)
or `__dunder__` — those are internal and may change in any release.

## Changelog

Every release includes a `CHANGELOG.md` entry generated by
[Release Please](https://github.com/googleapis/release-please) from Conventional
Commits. The entry lists breaking changes, new features, and bug fixes grouped by type.

## Support Window

| Track | Support |
|-------|---------|
| Latest MAJOR | Active: bug fixes + security patches |
| Previous MAJOR | Security patches only for 6 months after next MAJOR |
| Older | End of life |
