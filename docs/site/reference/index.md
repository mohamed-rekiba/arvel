## Concept guides vs API reference

Concept pages under [Getting Started](../getting-started/index.md), [Core Concepts](../core-concepts/index.md), [The Basics](../the-basics/index.md), and [Features](../features/index.md) explain *how* to use Arvel. The [API Reference](api.md) lists *what* each public symbol is, generated from source docstrings.

Read concepts first; use the API reference when you already know what you're looking for.
